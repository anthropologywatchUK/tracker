# anthropologywatchuk
Anthropology programmes across the United Kingdom are facing unprecedented pressures. Anthropology Watch UK provides a centralised, transparent record of institutional changes.

Modelled on the American Anthropological Association's Anthropology Watch tracker (https://americananthro.org/anthropology-watch/), this project aims to support informed public discussion, enable comparative analysis across institutions, and preserve an accurate historical record of what is happening to anthropology in UK higher education.
